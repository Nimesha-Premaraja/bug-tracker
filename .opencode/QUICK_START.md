# PDF Export Feature - Quick Start Guide

## What Was Implemented

A complete **PDF Bulk Export** feature for the Bug Tracking System that allows users to:
- Export multiple bugs to a professional PDF report
- Filter results before export (by search, status, priority, assignee)
- Choose export scope (current page or all matching bugs)
- Download PDF with naming convention: `BugReport_YYYY-MM-DD.pdf`

## How to Get Started

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

This will install `reportlab==4.0.7` needed for PDF generation.

### Step 2: Start the Application
```bash
# Using Docker (recommended)
docker-compose down
docker-compose up -d --build

# Or local development
export FLASK_APP=wsgi.py
export FLASK_ENV=development
flask run
```

### Step 3: Access the Application
- Open: http://localhost:5000
- Login with test credentials:
  - Email: `admin@example.com`
  - Password: `password123`

### Step 4: Try the PDF Export
1. Click **"Bugs"** in navigation
2. You'll see the bug list with an **"Export to PDF"** button (top-right)
3. Click the button to open export modal
4. Choose export scope:
   - **Current Page Only**: Export bugs on current page
   - **All Results**: Export all bugs matching filters
5. Click **"Export"** to download PDF

## API Endpoint Reference

### Export PDF Endpoint

**URL**: `POST /bugs/export-pdf`

**Authentication**: Required (login)

**Request Parameters**:
```
search=value            (optional) - Search in title/description
status=open             (optional) - Filter by status
priority=high           (optional) - Filter by priority  
assignee_id=5          (optional) - Filter by assignee
page=1                 (optional) - Current page number
export_all=true        (optional) - Export all vs current page
sort=created_at        (optional) - Sort field
order=desc             (optional) - Sort order
```

**Response**:
- 200 OK: Returns PDF file for download
- 302 Redirect: No bugs found or error occurred
- 401 Unauthorized: Not logged in
- 500 Error: PDF generation failed

**Example Request**:
```javascript
const formData = new FormData();
formData.append('search', 'login');
formData.append('status', 'open');
formData.append('export_all', 'true');

fetch('/bugs/export-pdf', {
    method: 'POST',
    body: formData
})
.then(response => response.blob())
.then(blob => {
    const url = window.URL.createObjectURL(blob);
    const link = document.createElement('a');
    link.href = url;
    link.setAttribute('download', 'BugReport_2026-08-05.pdf');
    link.click();
});
```

## Configuration

All PDF settings in `config.py`:

```python
PDF_FONT_SIZE = 10                  # Font size (default)
PDF_PAGE_SIZE = 'A4'                # Paper size
PDF_MARGIN = 20                     # Page margin in pixels
PDF_MAX_BUGS_PER_EXPORT = 500      # Max bugs per export
PDF_BUGS_PER_PAGE = 20             # Bugs per page before break
```

Modify these values in `config.py` to customize PDF generation.

## Troubleshooting

### Problem: "Export to PDF" button doesn't appear
**Solution**: 
1. Clear browser cache (Ctrl+Shift+Delete)
2. Ensure `pdf_export.css` and `pdf_export.js` loaded (check browser DevTools)
3. Restart Flask application

### Problem: "Module not found: reportlab"
**Solution**:
```bash
pip install reportlab==4.0.7
```

### Problem: PDF doesn't download
**Solution**:
1. Check browser console for errors (F12)
2. Verify network request succeeds (Network tab)
3. Check server logs for errors: `docker-compose logs web`

### Problem: PDF contains wrong data
**Solution**:
1. Verify filters applied correctly in URL
2. Check that bugs in database are correct
3. Try exporting smaller dataset first

### Problem: Large exports timeout
**Solution**:
1. Export "Current Page Only" instead of "All Results"
2. Apply more restrictive filters
3. Increase timeout in server config if needed
